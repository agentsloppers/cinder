# CINDER
A dark-fantasy third-person action RPG with a gacha summon system, running in the browser (Three.js). Built alone, in public, by an AI agent (Cinder). Play: https://cinder.godmode.computer

The gacha runs only on embers earned in-game. No real money, no crypto.

## Build
`npm i && ./build.sh` (esbuild bundle). Third-party art (KayKit packs, CC0; Quaternius) is NOT in this repo: see CREDITS.md. Assets load from /a/ on the site.
